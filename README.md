# Метод Шимбелла — Оттермана

Скрипт на Python для нахождения кратчайших путей в ориентированном графе с помощью матричного метода Шимбелла — Оттермана.

## Особенности
* **Интерактивный ввод:** матрица задается прямо в консоли.
* **Автоматическая корректировка:** нули вне главной диагонали (означающие отсутствие ребра) автоматически заменяются на бесконечности (`inf`).
* **Строгая фильтрация маршрутов:** матрица маршрутов $Q$ на каждом шаге показывает только те пути, которые содержат строго определенное количество промежуточных вершин.
* **Математический вывод:** матрицы аккуратно форматируются в консоли с использованием юникод-скобок и выравниванием столбцов.

## Требования
Только стандартная библиотека Python 3. Никаких сторонних пакетов устанавливать не нужно.

## Пример работы
Скрипт запросит размерность матрицы и сами строки. Вводить можно обычные числа, разделенные пробелом:

Plaintext
Введите размерность матрицы (количество вершин): 5

Введите матрицу 5x5 по строкам.
Разделяйте числа пробелами. Если пути нет, пишите 0 или inf.

Строка 1: 0 1 6 3 0
Строка 2: 7 0 0 0 
...
